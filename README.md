# 🚀 Node.js MySQL User Management System

A User Management System built using Node.js, Express.js, MySQL and EJS as part of my Web Development Learning Journey.

## 🛠️ Technologies Used

- Node.js
- Express.js
- MySQL
- EJS
- HTML
- CSS
- JavaScript
- Faker.js
- Method Override

## 📚 Features

- Display total number of users.
- View all registered users.
- Create new users.
- Edit existing user information.
- Update usernames with password verification.
- Delete users.
- Generate unique user IDs using Faker.js.
- Connect and interact with a MySQL database.

## ⚙️ Installation and Setup

1. Clone the repository.

2. Install dependencies:

```bash
npm install
```

3. Create a MySQL database and import the provided schema.sql file.

4. Create a `.env` file and configure your database credentials.

5. Start the server:

```bash
node index.js
```

6. Open your browser:

```text
http://localhost:8080
```
